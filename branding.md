# 🎨 Trovina.io – Complete Brand & UI Color System

## 🔑 Core Brand Colors

**Primary Background (Brand Base)**  
- `#0F0F0F`

**Primary Text & Buttons**  
- `#FFFFFF`

**Main Body Text (Soft White)**  
- `#F9F9F9`

These colors define the core identity of Trovina.io.

---

## 🧱 UI & Structural Neutrals

**Card & Section Backgrounds**  
- `#1F1F1F`

**Borders, Dividers, Subtle Lines**  
- `#2D2D2D`

**Secondary Text / Labels**  
- `#6B7280`

**Subtext / Descriptions / Meta Text**  
- `#9CA3AF`

**Navbar / Overlay Background**  
- `rgba(15, 15, 15, 0.8)`

---

## ⚙️ Functional Status Colors (Non-Brand)

**Success / Completed States**  
- `#22C55E`

**Warning / Processing States**  
- `#FACC15`

**Error / Alerts / Close Actions**  
- `#EF4444`

---

## 💻 Code & Demo Highlight Colors (Decorative Only)

Used exclusively inside code blocks and visual demos. Not part of brand identity.

- Blue: `#60A5FA`  
- Purple: `#A855F7`  
- Yellow: `#FBBF24`  
- Green: `#4ADE80`

---

## 🧠 Logo Color Rules

**Allowed**
- White logo on dark background → `#FFFFFF`
- Black logo on light background → `#0F0F0F`

**Not Allowed**
- No gradients  
- No additional colors  
- No shadows  
- No transparency  

---

## ✅ Final Summary

Trovina.io uses:
- One primary dark color
- One primary light color
- Neutral grays for structure and hierarchy
- Minimal functional colors only when necessary

This system is premium, scalable, enterprise-ready, and future-proof.
